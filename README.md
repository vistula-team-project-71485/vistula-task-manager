## Description

This project is a simple Task Manager web application connected to a Supabase PostgreSQL database.

It allows users to manage tasks through a web interface.

## Features

- Create new tasks.
- Display all tasks.
- Edit existing tasks.
- Delete tasks.
- Mark tasks as completed or not completed.
- Store tasks in a Supabase database.

## Technologies Used

- HTML
- CSS
- JavaScript
- Supabase
- PostgreSQL
- GitHub
- GitHub Pages

## Database

The application uses a Supabase table named `tasks` with the following columns:

- `id` – unique task identifier.
- `title` – task title.
- `description` – task description.
- `completed` – task completion status.
